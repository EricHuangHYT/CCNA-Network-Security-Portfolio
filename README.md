## 🔍 Why This Matters for Cybersecurity
In modern cybersecurity roles (such as a SOC Analyst or Network Security Engineer), understanding network infrastructure allows you to:
1. **Analyze Packet Captures (PCAPs):** Trace abnormal TCP handshakes, ARP spoofing, or unauthorized traffic directly back to switch ports and VLANs.
2. **Interpret SIEM Logs:** Correlate firewall blocks and routing anomalies with actual network boundaries.
3. **Mitigate Layer 2 Attacks:** Implement port security and DHCP snooping to prevent malicious actors from plugging rogue devices into corporate floors.
